# Gracefield Foods & Farms · website preview

Static HTML review build for Gracefield Foods & Farms, an African kitchen with its own farm near Edmonton, Alberta.
This is a design preview for client review, not the live site (that will be built in WordPress). Search engines are asked not to index it.

- `homepage-preview.html` · homepage
- `menu-preview.html` · full menu (generated)
- `menu-data.json` · menu source data
- `tools/build_menu.py` · rebuilds the menu page, homepage favourites, schema and asset versions: `python3 tools/build_menu.py`

Menu, prices, hours, address and the farm photo are draft content to be confirmed by the client.
